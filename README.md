# 極限造園王 v1.1

適合高中算幾不等式的三人觸控課堂遊戲。三位學生在同一畫面各自解題，各自計時、使用求救卡與計分。

## 開始使用

下載並解壓縮後，直接用 Edge 或 Chrome 開啟 `index.html` 即可。所有程式、圖片都在檔案包內，不需要安裝套件、登入帳號或設定 API 金鑰。

選擇座號（可不填），老師按「開始挑戰」。每題有四個小關：讀懂任務、找到界線、最佳條件、完成任務。答對後顯示本步說明，學生按「前往下一關」繼續。

數字題可點選畫面上的數字鍵盤，先選欲填寫的欄位再輸入。實體鍵盤也能輸入數字、退格；數值欄位按 Enter 可提交。正確數值都是整數，適合心算。

## 發布到 GitHub Pages

1. 在 GitHub 建立 repository，例如 `extreme-garden-amgm`。
2. 選 **Add file → Upload files**。上傳解壓後的 `index.html`、`style.css`、`engine.js`、`app.js`、`assets` 資料夾及其內容。`README.md` 與 `.nojekyll` 也可一起上傳。
3. 請確認 repository 根目錄直接看得到 `index.html`，且所有插畫在 `assets` 裡。不要只上傳 ZIP，也不要讓 `index.html` 多包在一層資料夾內。
4. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**，資料夾選 **/(root)**，按 Save。
5. GitHub 完成發布後，從 Pages 頁面點選提供的網站網址。

發布步驟參考 [GitHub 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

圖片路徑都是相對路徑，可用在 GitHub Pages 的 repository 子路徑，不必修改程式。

## 教師設定

預設：每人 3 題、基本題每題 120 秒、進階題 180 秒、每題最多 4 張求救卡、每答錯一次扣 2 分、座號 1～30、顯示插畫與倒數。

- 基本題預設全部啟用：花園、三角旗幟、泳池、倉庫、機器人。
- 三數進階題預設關閉：紙盒裁角、三變數貨箱。勾選總開關後，可分別選擇進階題型。
- 同一輪三位同學的題型與順序相同，數字各不相同；每人獨立前進。
- 「深色模式／淺色模式」可隨時切換，會保存在本機偏好中；教師設定也可控制。
- 「插畫：開／關」隨時套用，數學尺寸圖仍保留。教師設定也可控制插畫。
- 展開求救提示時，該區暫時收起插畫及完整題幹，保留關鍵條件，讓提示與操作按鈕完整呈現。第二關起顯示精簡條件，放大幾何圖及尺寸標示。第一關保留完整題幹。
- 開啟教師設定會自動暫停；關閉後回到原本的遊戲狀態。插畫與深色模式立即套用，其餘設定從下一輪生效。
- 設定保存在目前瀏覽器的本機偏好中；換瀏覽器或清除資料會恢復預設。
- 「暫停」會停止所有人的倒數。每一步完成的解說頁、本題成果頁也不扣解題時間。
- 一題逾時只保留已完成小關分數，未完成小關為 0 分；顯示正確尺寸與結果，再由學生前進下一題。
- 「結束本輪」需確認，保留已完成小關得分；未完成小關與未開始題目為 0 分。

## 求救卡與評分

每題滿分 100 分，四個小關各 25 分。

| 完成方式 | 本小關基礎分 |
| --- | ---: |
| 獨立答對 | 25 |
| 使用提示後答對 | 15 |
| 展開完整救援，自動完成本小關 | 5 |

本小關得分 = max(0，基礎分 − 本小關答錯次數 × 教師設定扣分)。未完成小關為 0 分。

一張卡只提示目前小關，最多每小關使用一次；同一張卡可再展開完整救援，不重複消耗。完整救援只帶過當前小關，學生仍可獨立解後面的步驟。基礎分依最深的救援程度決定，不疊加扣分。

例如沒有答錯，四步獨立完成得 100 分，一步提示得 90 分；一步完整救援得 80 分。倒數不提供額外速度加分。

總成績顯示座號、各題分數、獨立完成小關數、求救卡使用次數；展開各題可回顧答案與四步得分。

## 題型與數學範圍

所有算幾項皆為正數，關卡同時檢查上下界及等號是否可達到。

| 題型 | 條件 | 最佳條件 |
| --- | --- | --- |
| 花園最大面積 | 2L+2W 固定 | L=W |
| 直角三角旗最大面積 | a²+b² 固定，a,b>0 | a²=b²，所以 a=b |
| 泳池最小周長 | LW 固定 | L=W |
| 倉庫最低外牆費用 | LW 固定，費用 4L+2W | 4L=2W |
| 機器人最小耗能 | E=x+c/x，x>0 | x=c/x |
| 紙盒最大容積（進階） | 正方形紙邊 s，0<x<s/2，V=x(s−2x)² | 4x=s−2x，所以 x=s/6 |
| 貨箱最大體積（進階） | a+b+c 固定，a,b,c>0 | a=b=c |

第二關一律呈現未化簡的原始算幾不等式，分數使用水平分式；不先計算數值界線。

兩數算幾：(u+v)/2 ≥ √(uv)，等號成立於 u=v。

三數算幾：(u+v+w)/3 ≥ ∛(uvw)，等號成立於 u=v=w。建議先教過三數版本再開啟進階題。

紙盒題的裁切未知數只有 x；它使用三個相連的項 4x、s−2x、s−2x 套用三數算幾。貨箱題則有 a、b、c 三個變數。三數算幾與未知數個數是不同概念。

## 插畫與檔案

六組主題、共 24 張關卡插畫由 GPT Image 製作，使用色鉛筆手繪風、人物帶寵物，無數學文字。每組延續同一角色與寵物，四步分別為讀任務、思考列式、動手調整、完成慶祝。透明背景可搭配亮色與深色模式；貨箱進階題沿用紙盒工坊角色。數值與尺寸另由網頁程式顯示，會隨題目變動。原始生成提示記錄在 `assets/illustration-prompts.json` 與 `assets/stage-illustration-prompts.json`。

程式：`index.html`（介面）、`style.css`（版面）、`engine.js`（數學題庫）、`app.js`（遊戲操作）。插畫：`assets/*.webp`。

## 教室顯示

寬螢幕採三欄，建議使用 1920×1080 或更高的 16:9 畫面並按全螢幕。窄螢幕改為三區縱向排列，適合在手機檢視及個別練習。

若畫面太小，可降低瀏覽器縮放或關閉插畫。特殊文字放大設定下，學生區會保留捲動能力，以免內容被裁切。

網頁全螢幕仍由瀏覽器與 Windows 管理；作業系統或電子白板本身的側邊選單需由裝置設定控制。

資料與圖片全部隨包提供，可在沒有網路的電腦使用。沒有外部字型、CDN、追蹤碼或網路連線需求。
